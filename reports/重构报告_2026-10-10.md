## 二、新架构

```
job/
├─ config/                配置：口径与屏蔽名单（改配置不动代码）
├─ src/
│  ├─ cli.mjs             统一入口
│  ├─ core/               ① 底座层 —— 不含任何平台选择器
│  │   cdp.mjs            CDP 连接/求值/导航/真人化鼠标键盘/可见性(207 行)
│  │   session.mjs        平台 + 标签页 + 视口 打包
│  │   io.mjs             数据路径与原子落盘
│  │   salary.mjs         薪资解析（K/万/年/元 统一）
│  │   criteria.mjs       屏蔽名单 / 标题相关性 / 技术栈判定
│  │   age.mjs            年龄限制探测器
│  │   dedupe.mjs         跨轮次去重集合
│  ├─ platforms/          ② 适配层 —— 唯一知道 DOM 选择器的地方
│  │   boss.mjs liepin.mjs job51.mjs zhaopin.mjs index.mjs
│  └─ commands/           ③ 流程层 —— 跨平台复用
│      login scan jd targets apply(含 verify) chat history daily
└─ data/ reports/ legacy/
```

**分层铁律**：`core` 不含选择器 → `platforms` 只做页面与结构化数据的翻译 → `commands` 只做编排。
新增平台 = 新增一个 `platforms/xxx.mjs` 并注册，流水线**零改动**。

## 六、重构中修正的 3 个实质缺陷

1. **猎聘聊天读取范围错乱** —— 旧 `lp_chat2.mjs` 读 `.text` 会混入左侧岗位卡文本，30 个会话末条完全相同，导致无法判断是否需要回复。新版从输入框向上定位聊天窗容器后再读。
2. **BOSS 标题过滤区分大小写** —— 旧正则 `/C\+\+|QT/` 漏掉小写 `c++软件工程师`，导致一批 C++ 岗混入投递清单。新版统一大小写不敏感并扩充技术域排除词。
3. **「状态未知」误判** —— 旧代码把页面正文里的「沟通过/已投递」当已投依据（实为推荐位文案），曾误判 6 例。新版明确区分：必须精确读按钮文本，且额度触顶单独归类为 `quota_blocked` 而非 `unknown`。

## 七、常用命令

```bash
node src/cli.mjs platforms                     # 平台参数速查
node src/cli.mjs login                         # 环境 + 四平台登录态
node src/cli.mjs daily --platform liepin,boss  # 每日全流程
node src/cli.mjs apply  --platform boss --retry-logs data/logs/boss-apply-xxx.json  # 只重投未落库
node src/cli.mjs verify --platform boss --probe                                    # 只读巡检，不点击
```

> Windows：所有命令需带 `NO_PROXY=127.0.0.1,localhost`，否则系统代理会劫持本地 CDP 连接。
